# 🧠 Think Board

A responsive note-taking web application with a Warm Amber theme and automatic RTL/LTR text support.

## ✨ Features
- **Full CRUD:** Create, read, edit, and delete notes via API.
- **Search & Sort:** Live search and date-based sorting (*Newest* / *Oldest*).
- **Modals & UX:** Quick view modal, delete confirmation, skeleton loading, and toast notifications.

## 🛠️ Tech Stack
React • TypeScript • Vite • Tailwind CSS v4 • shadcn/ui • Axios • Lucide React • date-fns • React Hot Toast

## 🚀 Quick Start
```bash
npm install
npm run dev
```
